# Site Essencial — Template Universal

Template comercial One Page moderno, responsivo e reutilizável para apresentação de empresas e profissionais de diferentes segmentos.

## Tecnologias

- HTML5
- CSS3
- JavaScript ES6+
- Sem frameworks
- Sem backend
- Sem banco de dados

## Estrutura

```text
site-essencial-universal/
├── index.html
├── css/
│   └── styles.css
├── js/
│   ├── config.js
│   └── app.js
├── assets/
│   ├── icons/
│   │   └── favicon.svg
│   └── images/
│       ├── hero-business.svg
│       ├── about-business.svg
│       ├── og-cover.svg
│       └── gallery-*.svg
├── PERSONALIZAR.md
├── ESCOPO.md
└── README.md
```

## Executar

Pode ser aberto diretamente pelo `index.html`. Para um teste mais próximo da publicação, use qualquer servidor local estático.

## Posicionamento visual

Esta versão do **Site Essencial** utiliza **minimalismo contemporâneo**: fundo claro, uma cor principal, tipografia forte, poucos efeitos e estrutura objetiva. O objetivo é funcionar como o primeiro nível da linha **Essencial → Profissional → Premium**, preservando qualidade profissional sem competir em sofisticação com os níveis superiores.
